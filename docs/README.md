| 文档 | 何时使用 |
| --- | --- |
| [文档维护](documentation-maintenance.md) | 识别沉淀信号、保存决策、纠错、交接或新增文档 |
| [建模工作流](modeling-workflow.md) | 新建模型、修改场景、运行脚本、验证和管理资源 |
| [参考建模工具](reference-modeling.md) | 视频抽帧、后台渲染、静态对照，以及标签重影、样条越界和材质诊断经验 |
| [当前状态与演进](workspace-status.md) | 恢复工作、区分已实现基础与后续建议 |

项目特有的信息留在 `projects/<项目名>/README.md`；有新的跨项目专题时再新增文档并在此链接。不为每次会话单独建页，不强制时间版本、frontmatter 或维护日志。
